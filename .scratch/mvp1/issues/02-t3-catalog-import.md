# 02 — T3-catalog-import: 4 канала входа, ТНВЭД-фильтр, дубли

**What to build:** 4 канала входа карточки (форма/клон/Excel-импорт/инвойс-парсер), двухфазный ТНВЭД-фильтр (ADR-022), защита от дублей (Q4), UI читает GET /products/drafts.

**Blocked by:** 01 (T3-catalog-schema)

**Status:** ready-for-agent

- [ ] Каналы входа производят DraftProposal: ручная форма; клон карточки (reuse ключей файлов, CAT-011); инвойс-парсер (золотой тест по fixtures/invoice-38.json: точные имена/qty/цены); Excel-импорт (CAT-012)
- [ ] POST /products/drafts/import → jobId; асинхронный job через OutboxPoller (ADR-015), UI поллит статус; 10 000 строк без блокировки UI; построчный протокол ошибок; файловые ошибки (нет дескриптора/неверная группа) отклоняют файл целиком
- [ ] POST /demo/seed-invoice — сервер читает fixtures/invoice-38.json → 38+2 DraftProposal для tenant; ТОЛЬКО при DEMO_ENABLED=true, иначе 404
- [ ] GET /products/drafts — tenant-scoped список DraftProposal; негативный AT-16 (без JWT → 401)
- [ ] ТНВЭД-фильтр двухфазный (ADR-022): на DraftProposal — красная пометка + подсказка «возможно 2710198200», импорт не блокируется; на карточке при Submitted — гейт «вне перечня И без решения»
- [ ] Две аудируемые кнопки на красной строке: «Исправить код» (выбор из перечня, строка → карточка) / «Не подлежит маркировке» (терминальный статус «вне скоупа», отдельный список с причиной/кем); аудит (кто/когда/основание)
- [ ] Эвристика наименования (п.15 Правил): маркеры моторного масла (масло, SAE, ATF, API, ACEA, GL-) при ТНВЭД вне перечня → усиленная подсказка «проверьте ТНВЭД»; тест на фикстуре Nomad (38 строк 27101919)
- [ ] Дубли (Q4): точный GTIN-дубль у tenant (не Archived) → 409 со ссылкой, вторая карточка не создана; Rejected-карточка → 409 + «Открыть и создать новую версию»; нечёткое совпадение (lowercase+trim бренд+модель+объём+SAE) → жёлтая плашка «Открыть существующую»/«Продолжить создание», «Продолжить» аудируется; другой tenant → не дубль; вне-скоуп строка → инфо-плашка без блока; Archived → создание разрешено
- [ ] Acceptance: (a) import → jobId, строки в /products/drafts; (b) 38 реальных → «добор»+красная+подсказка, 2 demo-строки из сида → зелёные; (c) /products/drafts tenant-scoped (AT-16); (d) seed-invoice только при DEMO_ENABLED, иначе 404; (e) золотой тест парсера; (f) две кнопки Q3 оперируют строками DraftProposal
