# Building Skills From Patterns

Promote a repeated workflow (3+ times) into `.cursor/skills/<slug>/SKILL.md`.

- Skill = on-demand procedure. Rule = always-on convention. Hook = on save/stop.
- Description: WHAT + WHEN, third person, trigger terms.
- No secrets, no Windows-only paths. SKILL.md under 500 lines.
- Prefer updating an existing skill over duplicates.
