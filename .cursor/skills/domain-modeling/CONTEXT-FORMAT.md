# CONTEXT.md Format

## Structure

```md
# {Context Name}

{One or two sentence description of what this context is and why it exists.}

## Language

**Order**:
{A one or two sentence description of the term}
_Avoid_: Purchase, transaction
```

## Rules

- Be opinionated. Keep definitions tight (1–2 sentences). Only project-specific terms.
- This repo already has a large `CONTEXT.md` (суть, глоссарий, вехи). Additive glossary edits; do not wipe the header or MVP scope.
