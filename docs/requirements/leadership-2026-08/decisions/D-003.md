## Decision details

**Question:** Who owns the data created in MarkFlow — the platform operator or the individual client organizations?

**Selected option:** Client Organization owns business data, scoped by LegalEntity. MarkFlow owns platform configuration, security telemetry, anonymised aggregates, and minimal immutable audit evidence.

**Approver name:** [Delegated Project Owner]
**Approver role:** Project Owner (delegated authority from leadership review)

**Approval date:** 2026-08-22

**Authoritative source/version:** MarkFlow_delegated_decision_records_and_prompts.md, decision table, dated 2026-08-22

**Affected MF-REQ IDs:** MF-REQ-060, MF-REQ-061, MF-REQ-062, MF-REQ-063, MF-REQ-064, MF-REQ-080, MF-REQ-081, MF-REQ-082

**Implementation authorization scope:** W1+ production deployment, data retention policies, export/deletion APIs

### Policy

1. Client Organization owns business data, scoped by LegalEntity.
2. MarkFlow owns platform configuration, security telemetry, anonymised aggregates, and minimal immutable audit evidence.
3. Implement export/deletion requests with retention/legal-hold evaluation, not direct deletion.
4. Audit trail is retained independently of business data lifecycle.

### Test/acceptance evidence required
- [ ] Data export API returns tenant-scoped data only
- [ ] Deletion request triggers retention/legal-hold check
- [ ] Audit trail survives business data lifecycle changes
