### Permission primitive

`resource:action:scope`

**Actions:** view, create, update, bulk_execute, confirm, approve, export, administer

**Scopes:** own, organization, legal_entity, site, warehouse, assigned

### Enforcement

- Backend enforces **deny-by-default**.
- Custom roles are explicit permission sets (not inherited).
- No UI required per permission cell — approved authorization model and enforcement tests are the requirement.
