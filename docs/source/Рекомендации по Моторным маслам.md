**Рекомендации по заполнению атрибутов**

Атрибут «Торговое Наименование товара» заполняются коммерческое название продукта в следующей последовательности: Вид масла, бренд, марка, вязкость, объёма

_Пример:_ **Моторное масло Castrol EDGE 0W-20 C5 объем 4 литра**
