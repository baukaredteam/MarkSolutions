# Каталог «Моторные масла»: 44 атрибута, справочники, инвойс

## Атрибуты (группы)

- Идентификация: GTIN [0-9]{14} (1), группа (2), категория (3), тип упаковки (4).
- Описание: торговое наименование (5), товарный знак (6), страна знака (7), состав (11), срок годности мес (12), вид товара (13), объём л (14), назначение (15), SAE (16), хранение (17).
- Классификация: КПВЭД (8), GPC (9), ТНВЭД (10).
- Соответствие: тип/№/даты документа, бессрочность (18–22), знак соответствия СТ РК/нет (23), знаки обращения EAC/нет (24).
- Упаковка: вид (25), материал (26), вес брутто (27), ед. (28), Ш/В/Г (29–31), фото ≥2 (32).
- Владелец GTIN: GCP (33), наименование (34), страна (35), адрес (36).
- Площадка: наименование (37), страна (38), адрес (39).
- Участник оборота: налог. номер (40), GCP (41), наименование (42), страна (43), адрес (44).

## Инвойс (фикстура docs/source/Инвойс…md): что есть / чего нет

Есть: наименование (→бренд/линейка/SAE/объём/мультипликатор/тара регулярками), ТНВЭД (в фикстуре 27101919 — ВНЕ перечня → отклонять фильтром с подсказкой), кол-во, цена, валюта USD (курс-снапшот; в ИС МПТ деньги НЕ идут), страна происхождения AE, продавец/площадка, получатель=tenant, №/дата, PI REF.

НЕТ (добор обязателен): GTIN (→GtinResolver: справочник→GS1→ввод), GCP, срок годности, дата производства, состав, декларация соответствия, вес/габариты/фото, ГТД (отдельная сущность со статусом «ожидается», блокирует doc/import).

Единицы маркировки = места × штук_в_месте (явное поле, превью расчёта).

## Каноническая модель КМ (ADR-006)

- base = AI01+GTIN14+AI21+serial (без GS; фикстура fixtures/codes_success).
- extended = base + GS+91+key + GS+92+check (GS=0x1D; фикстура fixtures/codes_error; в Excel GS теряется — витрины экранируем как <GS>, печать/операции только из структуры).
